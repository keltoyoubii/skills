# Grille de lecture d'une référence

Copier dans `niche/refs/<id>/fiche.md` et remplir à partir de `hook.jpg`, `shots.jpg`,
`analysis.json` et `meta.json`.

```markdown
# <id>

Compte : @… · Plateforme : TikTok | Instagram · Publiée le : …
Vues : … · Médiane du compte : … · Surperformance : …× · Engagement : …%
Durée : … s · Plans : … · Coupes/10 s : … · 1re coupe : … s

## Hook (0-3 s)
- Image à 0 s : (ce qu'on voit, cadrage, mouvement déjà en cours ou non)
- Texte à l'écran : « … » (mots, position, apparition à … s)
- Type : (voir taxonomie ci-dessous, 1 ou 2 max)
- Promesse : ce que le spectateur attend de voir s'il reste

## Format
(tuto, avant/après, POV, coulisses, liste, réaction, transformation, storytelling,
démonstration de savoir-faire, trend sonore…)

## Rythme et montage
- Coupes : … (régulières / accélèrent / ralentissent ; cf. cuts_by_third)
- Procédés visibles : jump cuts, zooms punch-in, speed ramps, transitions de raccord,
  B-roll, split screen, sous-titres mot à mot…
- Moment de relance (re-hook) : … s, comment

## Texte et sous-titres
Police (graisse, casse), taille relative, couleur, position par rapport aux zones
d'interface (haut 15 %, bas 25 %, bande droite des boutons), animation.

## Son
Voix off / face cam / musique seule / son tendance (non vérifié si inaudible).
Couverture sonore : … · Premier son à … s · LUFS : …

## Payoff et fin
Ce qui est livré, à quel moment. Boucle vers le début ? CTA (texte, oral, aucun) ?

## Pourquoi ça a marché (hypothèses)
1-3 hypothèses, chacune reliée à un élément observé. Niveau de confiance.

## Ce que Maeldan peut reprendre
1-3 procédés concrets, transposables à un compte de vidéaste / monteur / DA.
```

## Taxonomie des hooks

Choisir le ou les deux types dominants ; en inventer un si aucun ne colle, et le noter.

| Type | Signe observable |
|---|---|
| Résultat d'abord | Le rendu final ou le moment fort ouvre la vidéo, le « comment » suit |
| Avant / après | Deux états opposés montrés dans les 2 premières secondes |
| Question / boucle ouverte | Texte ou voix qui pose une question dont la réponse est en fin |
| Affirmation forte | Opinion tranchée ou contre-intuitive en texte ou à l'oral |
| Erreur / douleur | « Arrête de… », montre un défaut que la cible reconnaît |
| Coulisses | Envers du décor d'un tournage, d'un setup, d'un projet client |
| POV / identification | « POV : … », situation vécue par la cible |
| Mouvement / choc visuel | Action rapide, transition spectaculaire ou image inhabituelle dès la 1re frame |
| Liste / chiffre | « 3 … », progression annoncée |
| Défi / test | « J'ai essayé… », enjeu avec issue incertaine |
| Trend | Son ou format reconnaissable, détourné |

## Signaux de plateforme (à garder en tête, pas à surinterpréter)

- Les deux plateformes récompensent le temps de visionnage et le taux de complétion ;
  une vidéo courte revue en boucle peut dépasser 100 % de rétention.
- Instagram a publiquement cité les partages en message privé (« sends ») comme signal
  fort de portée hors abonnés. Confiance moyenne sur le poids exact : les plateformes
  changent leurs pondérations sans prévenir.
- Les sauvegardes signalent une valeur de référence (tuto, inspiration) ; utile pour un
  compte qui veut attirer des clients.
- Ce qui ne se voit pas dans les données publiques (rétention seconde par seconde) ne
  s'invente pas : seules les stats internes du compte de Maeldan le donnent.
